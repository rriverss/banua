# БАНЯ «КЕДР» — 6,0 × 4,5 м с террасой

Интерактивный проект кар­касной бани: **3D-модель**, **6 чертежей**, **ведомость материалов и смета**,
**технология монтажа** — в одном приложении, которое собирается в Docker.

Сделано на основе ваших исходников (демо-проект каркасного дома «Марго», 62 листа АР+КР и
спецификация пиломатериала): сохранена отработанная технология — винтовые сваи, обвязка брусом,
каркас 45×195, утепление 195 мм, двускатная кровля 30° — но планировка переработана под баню.

---

## Быстрый старт

```bash
docker compose up --build
```

Открыть **http://localhost:8080**.

Без Docker (для разработки):

```bash
cd app
npm install
npm run dev        # http://localhost:5173
npm run build      # production-сборка в app/dist
npm run schemes    # перегенерировать SVG-чертежи в app/public/schemes
```

## Почему всё сходится

Одна модель — три представления:

```
app/src/model/project.js   ← геометрия: оси, стены, проёмы, кровля, сваи, комнаты
        │
        ├── app/src/scene/*      → 3D-сцена (three.js)
        ├── app/src/schematics/* → SVG-чертежи (собственный генератор)
        └── app/src/model/bom.js → ведомость и смета
```

Изменили размер в `project.js` — пересчитались 3D, чертежи и смета. Никаких «двух правд»
(картинка отдельно, смета отдельно).

## Принятые решения

- **Фундамент — винтовые сваи.** Всесезонно, без земляных работ, ремонтопригодно, как в «Марго».
  Альтернативы (УШП, лента) описаны в разделе «Технология».
- **Каркас 45×195, шаг 600, ОСП-3 9 мм.** Технология из исходного проекта, проверена на доме 75 м².
- **Кровля металлочерепица 30°.** Дешевле мягкой черепицы на 80–120 тыс. ₽ при том же результате;
  вариант с мягкой черепицей описан в листе «Стропильная система».
- **Печь 12 кВт с баком 60 л**, дымоход «сэндвич» ⌀115, разделка по нормам.
- **Парная — липа + фольга**, мойка — керамогранит по гидроизоляции, КО — сосна и доска.

## План реализации

1. **Неделя 0.** Геология (пробные сваи), ТУ на электричество, утверждение планировки.
2. **Неделя 1.** Разметка, 20 свай, ростверк.
3. **Недели 2–3.** Пол, стены, перегородки, потолок, стропила.
4. **Неделя 4.** Кровля и водосток.
5. **Неделя 5.** Утепление, плёнки, окна и двери — контур закрыт.
6. **Недели 6–7.** Фасад, терраса, внутренняя отделка.
7. **Неделя 8.** Печь, инженерия, пуск и приёмка по чек-листам.

Подробно — в приложении, раздел «Технология».
