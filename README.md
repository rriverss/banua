# ТРИ ПРОЕКТА — барнхаус 10,0 × 9,5, баня 6,0 × 4,5 и баня «Палома» 11,0 × 6,5

Три самостоятельных проекта одной технологии в одном приложении: **3D-модель**, **7 чертежей**,
**ведомость материалов и смета**, **технология монтажа** — и переключатель в шапке, чтобы
сравнивать варианты на ходу.

| | Барнхаус «Марго» | Баня «Марго» | Баня «Палома» |
|---|---|---|---|
| Габарит | 10,0 × 9,5 м, тёплый блок 8 × 7 + Г-образная терраса 30 м² | 6,0 × 4,5 м + терраса 2,5 м (15 м²) | 11,0 × 6,5 м, тёплый блок 7 × 5 + Г-образная терраса 32 м² |
| Тёплый контур | **51,2 м²**: гостиная 28,7, спальня 9,3, сауна 5,9, душевая 3,6, санузел 1,9, гардероб 1,9 | **24,2 м²**: КО 12,3, парная 5,8, мойка 6,1 | **29,8 м²**: КО 17,3, парная 6,3, душевая 4,8, с/у 1,3 |
| Кровля | 116,1 м², 30°, конёк вдоль дома | 57,8 м², 25°, конёк вдоль дома | 81,1 м², **односкатная 9,8°** (1:5,8) |
| Свай | 31 ⌀108×2500 | 20 ⌀108×2500 | 23 ⌀108×2500 |
| Витраж | 8,0 × 2,55 м во фронтоне | 6,0 × 2,7 м в торце + треугольник фронтона | **3,1 × 2,26 м** + окна в пол 640 × 2260 |
| Смета | ≈ 3,66 млн ₽ (91 позиция) | ≈ 2,17 млн ₽ (74 позиции) | ≈ 2,65 млн ₽, 75 позиций (≈ 42,9 тыс. ₽/м²) |
| id | `margo-10x95` | `margo-6x45` | `paloma` |

Переключение — кнопками в шапке или ссылкой `?p=margo-6x45`; выбор запоминается в браузере.
Вкладка **«Проекты»** показывает карточки всех вариантов и таблицу сравнения по цифрам.

«Палома» собрана по исходникам застройщика (АР + КМ + КД, 74 страницы, ведомость материалов):
габарит 11,0 × 6,5, свайное поле 23 × ⌀108×2500 с обвязкой 150×150, каркас 40×150 шаг 600,
кровля односкатная 9,8° по стропилам 50×200 на двух прогонах LVL, печь 12 кВт в парной.
Модель повторяет эти узлы, поэтому её 3D, листы и смета сходятся с исходником по отметкам
(−2,855 / −0,750 / −0,455 / ±0,000 / +0,040 / +2,30…+3,17 / +3,72) и по площадям.

Первая версия (баня) сохранена как отдельный проект: у неё своя модель, свои 7 листов,
своя смета — ничего не потеряно при переделке под барнхаус.

Сделано по приложенным референсам (проект «Марго», 10,0 × 9,5 м): технология — винтовые
сваи, обвязка брусом, каркас 45×195, утепление 195 мм — и образ: графитовый фасад,
светлая лиственница на фронтонах, чёрная фальцевая кровля с коньком вдоль длинной оси,
витраж на всю высоту торца, Г-образная терраса под общей крышей, каменный цоколь.

## Быстрый старт

```bash
docker compose up --build
```

Открыть **http://localhost:8080**.

Без Docker (для разработки):

```bash
cd app
npm install
npm run dev            # http://localhost:5173
npm run build          # production-сборка в app/dist
npm run schemes        # SVG всех проектов → app/public/schemes/<id>/
npm run schemes:6x45   # только баня 6,0 × 4,5
npm run sheets         # PNG листов в /tmp для быстрой проверки
node softrender.mjs 1000 700 corner --project=margo-6x45   # 3D-рендер без браузера
```

## Почему всё сходится

Одна модель — три представления:

```
app/src/projects/
├── margo-10x95/            ← барнхаус 10,0 × 9,5
│   ├── project.js          ← геометрия: оси, стены, проёмы, кровля, сваи, комнаты
│   ├── bom.js              ← ведомость и смета (считается из project.js)
│   ├── build.js            ← 3D-сборка (three.js)
│   ├── scene.js            ← ленивый вход для 3D-чанка
│   └── sheets/*.js         ← 7 SVG-листов
├── margo-6x45/             ← баня 6,0 × 4,5 (та же структура)
├── paloma/                 ← баня «Палома» 11,0 × 6,5 по исходникам застройщика
│   ├── project.js          ← геометрия: оси 1…5 / А…Д, односкатная кровля, 23 сваи, Г-терраса
│   ├── bom.js              ← ведомость и смета 2 652 675 ₽
│   ├── build.js            ← 3D-сборка: сваи, обвязка, каркас, кровля-«пирог», терраса, печь
│   ├── scene.js
│   └── sheets/*.js         ← 7 листов: план, сваи, разрез, стена, кровля, фасад, узлы
└── index.js                ← реестр проектов, выбор активного
```

Изменили размер в `project.js` своего проекта — пересчитались его 3D, чертежи и смета.
Общий код (`scene/viewer.js`, `scene/materials.js`, `schematics/svg.js`, `ui/*`) один на оба
проекта, поэтому экраны и штампы одинаковые, а цифры — свои. Никаких «двух правд».

## Принятые решения

- **Фундамент — винтовые сваи.** Всесезонно, без земляных работ, ремонтопригодно, как в «Марго».
  Альтернативы (УШП, лента) описаны в разделе «Технология».
- **Каркас 45×195, шаг 600, ОСП-3 9 мм.** Технология из исходного проекта, проверена на доме 75 м².
- **Кровля — фальц RAL 7021, 30°, одна на дом и террасу.** Это то, что делает силуэт
  барнхаусом: гладкий тёмный скат, свес 700 мм, конёк вдоль длинной оси на прогоне 45×245,
  стойки 120×120 под коньком. Кровля 116,1 м², конёк +5,33 м.
- **Витраж в торце.** Вход через стеклянную стену 8,0 × 2,55 м: семь стоек, трансома 2,05 м,
  дверь 1000 × 2200. Выше — деревянный фронтон 2,43 м под свесом, разгруженный балкой 200×200.
- **Печь для сауны 9–12 кВт с камнями**, дымоход «сэндвич» ⌀115 сквозь кровлю, разделка по нормам.
- **Сауна — липа + фольга**, душевая и санузел — керамогранит по гидроизоляции, гостиная и
  спальня — сосна, шпунтованная доска, свод по стропилам.
- **Цоколь — каменный плитняк 0,35 м**, терраса — лиственница 28×140, ступени во всю ширину 10 м.
- **«Палома» — геометрия застройщика, а не переделка.** Оси, отметки, шаг стоек 600, пирог стены
  и кровли, свайное поле и проёмы взяты из PDF и сохранены; свои — только 3D, листы и смета.
  Забирка / обвязка / узлы описаны так, как в КМ, поэтому чертежи читаются вместе с исходником.

## План реализации

1. **Неделя 0.** Геология (пробные сваи), ТУ на электричество, утверждение планировки.
2. **Неделя 1.** Разметка, 31 свая, ростверк, цоколь.
3. **Недели 2–3.** Пол, стены, перегородки, потолок, стропила.
4. **Неделя 4.** Кровля и водосток.
5. **Неделя 5.** Утепление, плёнки, окна и двери — контур закрыт.
6. **Недели 6–7.** Фасад, терраса, внутренняя отделка.
7. **Неделя 8.** Печь, инженерия, пуск и приёмка по чек-листам.

Подробно — в приложении, раздел «Технология».

## Границы и оговорки

- Это **эскизно-рабочий** комплект для стройки «под себя», а не проект для экспертизы.
- Расчёт конструкций — по типовым решениям, без индивидуального статического расчёта.
- Цены — розничные, Московская область, ноябрь 2026, без скидок и логистики на объект.
- Перед стройкой уточните геологию, снеговой/ветровой район, требования местной администрации
  и паспорт выбранной печи.

## Лицензия и источники

используются как референс технологии и геометрии. Код проекта — свободно используйте и меняйте
под свои размеры.
